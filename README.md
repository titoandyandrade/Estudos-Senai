# 🏫 Estudos - SENAI

Este repositório foi criado para centralizar todos os meus projetos, exercícios práticos e documentações desenvolvidos durante as aulas no SENAI.

---

## 🗂️ Organização do Repositório

O projeto está dividido de acordo com as disciplinas e competências estudadas:

### 💻 Desenvolvimento de Software & Algoritmos
*   `CriandoSoftware`: Projetos iniciais e lógicas de programação.
*   `Laco_Para-For` / `Laco_Enquanto_FacaEnquanto`: Exercícios práticos de estruturas de repetição e lógica pura.
*   `Procedimento_Funcao`: Modularização de código e reaproveitamento de lógica.

### 📐 Modelagem de Sistemas (Nova Disciplina - Cursando)
*   `Modelagem_de_Sistemas/Requisitos`: Documentação de Engenharia de Software, incluindo Levantamento de Requisitos Funcionais (RF) e Não Funcionais (RNF).
*   `Modelagem_de_Sistemas/Diagramas`: Modelagem visual de sistemas utilizando diagramas arquiteturais (Casos de Uso, Fluxogramas, etc.).

### ⚡ Fundamentos de Eletroeletrônica Aplicada (Nova Disciplina - Cursando)
*   `Eletroeletronica_Aplicada/Relatorios`: Anotações teóricas, conceitos de grandezas elétricas (tensão, corrente, resistência) e relatórios de medições.
*   `Eletroeletronica_Aplicada/Circuitos`: Esquemas elétricos, simulações virtuais e registros de montagens práticas de circuitos.

---

## 🛠️ Tecnologias e Ferramentas Aplicadas

*   **Linguagens**: Python, Portugol (VisualG).
*   **Modelagem**: Ferramentas de engenharia de software para diagramação de sistemas.
*   **Controle de Versão**: Git e GitHub.
